# 🌍 Siliguri Travels

A simple travel booking website for Siliguri and nearby destinations.

## ✨ Features
- 🏞️ Place Booking System
- 📞 Contact Us Form
- 🔐 Admin Login Panel
- 📊 View Bookings & Messages
- 📅 Date Validation
- 📧 Email & Form Validation

## 🛠️ Built With
- Python (Flask)
- HTML, CSS, JavaScript
- SQLite Database
